# Prisoner 15: status and plan

For a stressed person who used to be fit. The aim is that he keeps coming back: the app shows the comeback, forgives a missed day, and never becomes one more demand.

## Status: v0.5.0

Done: Strength tab (push-ups and squats, weekly variations, even rounds, equal sides, nose pad, 15-minute cap, progression, morning reminder), Run tab (Galloway run/walk steps, spoken timer with the screen off, loud cues, flexible length, run log), Record, and the v0.5 "Comeback" set: comeback line (first capacity to today's), test day every four weeks (offered, replaces that day's session, open sets, equal sides, sets the capacities), never miss twice (after a missed day the home screen preselects the short session and the reminder text changes), Sunday weekly sentence, 7/30/100-day milestones, backup to and from a file.

Not yet confirmed on a phone: nose pad (v0.3.0), loud cues, a full run with the screen off, the reminder and its missed-day text, the backup file picker.

Notes: test day treats the stopped set (form slows, not failure) as the new capacity; targets stay a fraction of it. The comeback line starts from the first capacities stored, or from the capacities at the time of the v0.5 update for older histories.

## v0.6 "Eyes-free"

7. Spoken cues in Strength (round, rest, side) and a 3-2-1 countdown before the first set.
8. One tension cue per set (from *The Naked Warrior*: crush the floor, glutes tight, sharp exhale).

Starts after the owner has used the nose pad for a week, because both change the workout screen.

## Later, only if the owner asks

- Path toward the one-arm push-up and the pistol; 1-2-3 ladder mode on uneven days.
- 5 km goal on the Run tab; distance and walking/running detection from the step sensor or GPS (adds permissions).
- Camera squat counting.

## Not planned

Breathing or meditation screens, badges, points, sharing, more exercises, more settings, anything that punishes a missed day, static back exercises.
