Prisoner 15 1.0.0, the final build: the feature set is complete and nothing more is planned.

**What it is.** A minimal, offline Android morning routine: push-ups and squats, never more than 15 minutes, always an even number of rounds, one-sided exercises in pairs with equal repetitions on both sides, no static back exercises. A separate Run tab with a Galloway run-walk timer. No account, no network permission, no libraries.

**What is in it.**
- Strength: weekly variations, energy levels, nose-pad push-up counting (proximity sensor optional), progression after two clean sessions, morning reminder.
- Run: run/walk steps that move up after two comfortable runs of 20+ minutes, spoken cues with the screen off, loud cues, flexible length, run log. Optional walking and running detection (step sensor, off by default; the distance is an estimate).
- Path: six steps from the uneven push-up to the one-arm push-up and from the Bulgarian split squat to the pistol. You move up by choice once the capacity reaches 10. Optional 1-2-3 ladders on the light days.
- Comeback: where your numbers started and where they are, a test day every four weeks, a missed day never counts twice, weekly sentence, milestones, backup to and from a file.
- Workout voice: 3-2-1, round, exercise, side and target.

**Install.** Download `Prisoner15-1.0.0.apk` below and open it on the phone (allow installing from this source when asked). It is signed with the same key as earlier builds, so it installs over them and keeps your history.

**Tests.** Engine, cadence, screen and Java tests pass. **Not tested on a phone:** the path steps and their set-ups, the ladders, the walking and running detection (the running threshold of 135 steps per minute is a guess), the workout voice and the 3-2-1, the nose pad, the loud run cues, a full run with the screen off, the reminder and its missed-day text, and the backup file picker.
