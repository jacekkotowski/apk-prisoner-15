Prisoner 15 1.1.0: mixed sessions, and a simpler app.

**Changed: every session has two halves.**
- Warm-up half: always the first 2 rounds, standard push-ups and squats (0.6 of your capacity, flat).
- Heavy half: the remaining rounds, uneven push-ups and Bulgarian split squats, both sides each round with equal repetitions (0.7 of the one-sided capacity on moderate days, 0.6 on light days, 0.1 more on Strong; the last heavy round is 15% higher on moderate days).
- 2 rounds = standard only; 4 rounds = 2 standard + 2 one-sided; 6 rounds = 2 + 4. Exhausted, a missed day and Sunday are 2 standard rounds. Monday, Wednesday, Friday moderate, Tuesday, Thursday, Saturday light, Sunday recovery: no more standard days and uneven days. If a session does not fit in 15 minutes it drops heavy rounds, never the two standard ones.
- Every variation in the session (standard and uneven push-ups, squats, Bulgarian split squats) moves up after two clean, comfortable sessions, each on its own. The path levels (archer, one-arm, box pistol, pistol) apply to the heavy half.
- Home screen: one plan line per exercise (for example "Push-ups 13 · 13", "Uneven push-ups / side 6 · 6"), the books and chair text only when the heavy half is in the session, and one message line instead of five (the first that applies: resume, test day, missed day, next path step, Sunday sentence, milestone, comeback; the result of what you just did comes before them). The milestone line shows only when your day count lands on 7, 30 or 100. Header: Record, Setup.
- The Path moved into Record, with Next step and Step back.

**Cut.** 1-2-3 ladders. Walking and running detection on the Run tab (step sensor, steps per minute, the estimated distance) and with it the physical-activity permission. Old runs keep their steps and km in the data but they are not shown.

**Your history.** It is kept: the log, runs, capacities, best sets, paths and test date. The state is upgraded when the app opens, and backups from v1.0 or older load. **Save a backup in your current version first** (Setup, Save backup), and keep it. A backup saved by 1.1.0 cannot be loaded by older versions.

**Install.** Download `Prisoner15-1.1.0.apk` below and open it on the phone. It is signed with the same key as earlier builds, so it installs over them.

**Tests.** Engine tests (every round count, day and energy: even rounds, 2 standard first, equal sides, inside 15 minutes; progression of all four variations; migration of a v0.8-shaped state) and the screen test pass on a desktop browser; the Release workflow runs both before it builds. **Not tested on a phone:** the mixed session, the message line, Path inside Record, migration of your real history, the loud run cues, a full run with the screen off, the reminder and its missed-day text, the backup file picker, and the workout voice with the new round order.
